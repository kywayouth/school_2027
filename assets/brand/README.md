# KYWA 공식 웹용 자산

사용자가 제공한 PDF 호환 Illustrator 원본 중 서비스에 필요한 로고 조합형과 캐릭터 응용동작만 추출했습니다. 원본 매뉴얼 전체는 배포하지 않습니다.

- `logos/*.webp`: 기관·7개 시설의 공식 로고. 흰 바탕, 원래 색상·비율·글자 조합 유지.
- `characters/*.webp`: 기존 기본형·응용동작. 포즈·표정·색상을 새로 만들거나 바꾸지 않음.
- `provenance.json`: 원본 파일명, SHA-256, 페이지, 추출 위치, 최종 크기·용량.

현재 실행 환경에는 SVG 변환기가 없어, 긴 변 4,800px로 원본을 렌더링한 후 경량 무손실 WebP로 제공합니다. 글자를 다시 입력하지 않았습니다. 웹에서 원본 비율을 유지하고 흰 배경 위에 표시해야 합니다. CSS 필터, 색 덮기, 잘라내기, 비율 왜곡을 적용하지 마세요. 로고에는 별도 레이아웃 여백도 확보하세요.

캐릭터의 시설별 배정은 이 서비스의 소개 이미지 선택입니다. 공식 시설 대표 캐릭터 지정이나 해당 활동의 실제 제공을 의미하지 않습니다.

로컬 원본에서 다시 내보내기: `scripts/export-ci-assets.py`. 필요 도구는 Python Pillow와 Poppler `pdftoppm`이며, `--source-root`와 `--pdftoppm` 옵션으로 위치를 지정할 수 있습니다. 원본 파일이 없는 공개 저장소만으로는 재생성되지 않습니다.
